InDesign-Plugin (UXP) für KI-gestütztes Korrekturlesen: Rechtschreibung und Grammatik, Typografie nach DIN 5008 und Lektorat. Die Prüfung läuft über die OpenAI-API mit dem eigenen API-Key, der verschlüsselt auf dem jeweiligen Rechner gespeichert wird.

## Funktionen

- **Prüft** Rechtschreibung, Grammatik, Typografie nach DIN 5008 und macht Lektoratsvorschläge.
- **Wahlweise** das ganze Dokument, einen Seitenbereich oder nur die Auswahl.
- **Fehlerliste nach Seiten:** Anzeigen, Übernehmen, Ignorieren oder ins Wörterbuch aufnehmen, auch einzeln in einer kompakten Ansicht.
- **Prüfstand und Historie im Dokument:** Wer die Datei öffnet, sieht denselben Stand. Mehrere Benutzer werden unterstützt und im Verlauf angezeigt.
- **Praktische & kompakte Ansicht** zum effizienten korrigieren.
- **Eigenes Wörterbuch** mit Kategorien, zum Teilen per Export und Import.
- **Statistik**, CSV-Export und optionales Prüfprotokoll.
- **Sicherheit** durch eigenen OpenAI-API-Key, welcher nur auf dem eigenen Rechner gespeichert wird.
- **Farben, Modell und Gründlichkeit** lassen sich einstellen, helles und dunkles Design wird unterstützt.
- **Updates mit einem Klick** direkt im Plugin.

## Installieren

1. **[TP Lektor herunterladen](https://github.com/Blacktoastx/tp-lektor/releases/latest/download/TP-Lektor.ccx)** (immer die neueste Version).
2. Doppelklick auf die Datei. Creative Cloud installiert das Plugin.
3. In InDesign: Fenster → Zusatzmodule → TP Lektor.

Neue Versionen meldet das Plugin selbst. Installiert wird ein Update genauso per Doppelklick auf die neue `.ccx`.
